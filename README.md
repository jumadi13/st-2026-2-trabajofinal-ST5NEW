# Trabajo final — Series de Tiempo (2026-II)

Repositorio del trabajo final del curso.

## Estructura

- `datos/`: archivos CSV originales entregados para el análisis.
- `R/`: funciones y procedimientos organizados por etapa.
- `analisis/correr-todo.R`: punto de entrada para ejecutar el análisis completo.
- `informe/`: documento Quarto y su salida renderizada.
- `exposicion/`: diapositivas de la sección 8.
- `figs/`: figuras generadas al ejecutar el análisis.
- `sesion-info.txt`: información de la sesión de R utilizada.

## Antes de ejecutar

1. Copiar en `datos/` los tres archivos CSV originales, sin modificarlos.
2. Completar los scripts de `R/` y `analisis/correr-todo.R`.
3. Completar `informe/informe.qmd` y renderizarlo a HTML o PDF.
4. Agregar en `exposicion/` el PDF final de las diapositivas. El nombre previsto es `ST5NEW.pdf`.
5. Generar `sesion-info.txt` con la salida de `sessionInfo()`.

Los archivos `.gitkeep` mantienen en Git las carpetas que todavía están vacías.
